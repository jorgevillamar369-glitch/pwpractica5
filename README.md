# Pwa5 · Gestión de tareas por equipos

Práctica 5 de Programación Web Avanzada. Aplicación en PHP y MySQL para organizar proyectos y tareas con tres roles: administrador, gerente de proyecto y miembro del equipo.

- Sitio: https://pwapractica5.infinityfreeapp.com
- Repositorio: https://github.com/jorgevillamar369-glitch/pwpractica5
